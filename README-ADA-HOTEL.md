# ADA Hotel — Guest Service demo

Неофициальный демонстрационный проект в репозитории. Не является официальным сайтом или сервисом ADA Hotel.

## Что добавлено
- Адаптивный сайт отеля и пример меню.
- Форма заявки: этаж, номер комнаты, тип обращения, комментарий.
- FastAPI backend и хранение заявок в SQLite.
- Telegram-бот: персонал получает сообщение с этажом, комнатой и комментарием. Кнопка «Ответить гостю» позволяет отправить текстовый ответ, который появится на сайте.
- Проверка статуса заявки на сайте и генератор QR-кодов.

## Развёртывание сервера
Разверните папку backend как Python web service на Render, Railway или другом хостинге. Команда установки: pip install -r requirements.txt. Команда запуска: uvicorn main:app --host 0.0.0.0 --port $PORT. Рабочая директория: backend. Добавьте переменные из backend/.env.example. Для SQLite нужен постоянный диск/volume, иначе данные могут пропасть после пересборки.

В assets/config.js укажите публичный URL backend. В CORS_ORIGINS укажите адрес сайта.

## Подключение Telegram
1. Создайте бота через официальный BotFather и храните токен только в переменных окружения сервера.
2. Откройте личный чат с ботом и отправьте /start.
3. Узнайте свой числовой Telegram chat ID безопасным способом и задайте TELEGRAM_ADMIN_CHAT_ID.
4. Перезапустите backend и отправьте тестовую заявку с сайта.
5. Персонал получит этаж, комнату, комментарий и кнопки. Нажмите «Ответить гостю» и отправьте следующим сообщением текст ответа. Ответ появится в блоке статуса заявки на сайте.

Первая версия рассчитана на один служебный Telegram-чат и текстовые ответы. Не размещайте токен бота в JavaScript или GitHub.

## Перед реальным использованием
Получите письменное разрешение отеля на использование названия, логотипа, фотографий и контактных данных. Меню и цены сейчас демонстрационные. Проведите тестирование на вымышленных номерах. Перед запуском для гостей добавьте аутентификацию сотрудников, rate limiting, HTTPS, роли, мониторинг и правила хранения данных. GitHub Pages размещает только frontend; Python API необходимо развернуть отдельно.
