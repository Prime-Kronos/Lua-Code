# Amu Sazan Menu

Демонстрационный сайт электронного меню и Telegram-панели ресторана.

## Возможности
- Адаптивное меню, категории, корзина и сумма заказа.
- Заказ с выбором наличных или оплаты картой у официанта.
- Вызов официанта по номеру стола.
- Отзывы приходят в Telegram.
- Кнопки администратора: «Ответить клиенту», «Принять заказ», «Отклонить».
- Ответ администратора появляется в уведомлениях сайта клиента.
- QR-коды: меню, Google Maps review, Apple Maps карточка места.

Важно: это демонстрационный проект, не официальный сайт ресторана. Блюда и цены примерные и не подтверждены рестораном. До реального использования согласуйте меню, цены и разрешение ресторана.

## Запуск
Требуется Python 3.11+.
1. Перейдите в backend.
2. Выполните pip install -r requirements.txt.
3. Задайте BOT_TOKEN (новый токен после отзыва старого) и BOT_ADMIN_ID (Telegram user ID администратора).
4. Запустите uvicorn main:app --host 0.0.0.0 --port 8000 из папки backend.
5. Откройте http://127.0.0.1:8000.

Чтобы узнать ID, сначала откройте бота и отправьте /start. Если BOT_ADMIN_ID не задан, бот покажет ваш ID. Укажите его в переменной окружения и перезапустите сервис.

## Render
Создайте Web Service из Prime-Kronos/Lua-Code или используйте Blueprint из render.yaml. В Environment добавьте BOT_TOKEN и BOT_ADMIN_ID. Токен храните только в секретных переменных Render, не в исходниках и не в GitHub.

## Ограничения демо
Заказы и уведомления хранятся в памяти процесса и очищаются после перезапуска. Ответ клиенту доставляется на сайт в том же браузере/сессии, пока клиент может открыть страницу снова. Онлайн-эквайринг не подключён: оплата картой выполняется у официанта через терминал.

Apple Maps QR открывает карточку места. Apple Maps не предлагает такую же публичную форму текстовых отзывов, как Google Maps.
